Planning

Discussion Planning

開工前先把架構、交付順序和切片方式收斂成可執行共識。

現在結論是什麼

先用人話講清楚這輪 planning 的目前結論、影響範圍，以及能不能安全地下放。

還差什麼才能正式開工

說明現在卡在哪裡、誰該動、還差哪些條件才能把共識推進到下一步。

最近一次共識推進

只保留真正會改變判斷的轉折，不把所有內部事件都攤出來。

Open Issues 與追蹤

把會阻擋流程的問題與只是追蹤中的事項分開看，避免每個 issue 都看起來一樣嚴重。

這輪切出的工作

看這輪 planning 產出的 execution slices，以及目前已下放多少、完成多少。

Planning Internals 只有在追 readout、artifact、baton loop 細節時才需要看。
