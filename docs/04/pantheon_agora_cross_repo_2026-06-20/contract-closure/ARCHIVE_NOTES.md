## What this pack closes (G1–G5 from the contract-layer gap analysis)

- **G1 widget_spec canonical conflict** -> `02_schema_coexistence_and_migration.md`:
  XR-001 v1 stays frozen; A3 model is adopted additively as `WidgetSpec 2.0` /
  `DashboardRecipe 2.0` under `services/control-plane/specs/agora/v2/` with a
  separate `bundle_index.v1_1.json`. No XR-001 hash is invalidated.
- **G2 missing routes/capabilities** -> `03_*` (servant + workshop), `04_*`
  (dashboard CRUD + ETag/If-Match/Idempotency-Key concurrency). New capabilities
  `agora.servant.v1`, `agora.dashboard.v2`; `agora.workshop.v1` gains the
  `/bff/agora/workshops` prefix.
- **G3 compatibility manifest** -> `06_*` + `compatibility_manifest.schema.json`:
  canonical path `docs/contracts/agora/dev-compatibility-manifest.json`, exact
  commit/hash semantics, deployment gate.
- **G4 chart library** -> `05_*`: keep Recharts; add ECharts + react-grid-layout.
- **G5 UI IA** -> `05_*`: three-tab IA (Trading Room / Strategy Workshop /
  Strategy Execution & Performance) with legacy-route redirects.
