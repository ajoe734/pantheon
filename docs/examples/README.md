# Example Payloads

This directory holds screen-oriented example payloads used by:

- Pantheon BFF implementation
- front-end type generation and integration
- Lovable task packets
- QA fixtures

## Available Examples

- `F-042-review-page.json` — Deployment review composed view payload
- `RW-04-experiment-launch.json` — Research Workbench experiment launch, status, history, and cancel payloads
- `bff-remaining-catalog.json` — Remaining list/detail read surfaces (PS/CP/DP/RT) payloads
