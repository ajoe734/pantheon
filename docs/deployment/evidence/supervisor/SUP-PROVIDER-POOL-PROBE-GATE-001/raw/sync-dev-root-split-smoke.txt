# scripts/sync-dev-root.sh split-root smoke (SUP-PROVIDER-POOL-PROBE-GATE-001 acceptance 5)
#
# Harness: a bare origin, a `devroot` checkout (the default path the script used
# to be the only thing it knew about), and an `activeroot` checkout standing in
# for the live supervisor's real cwd. Both roots are put one commit behind
# origin/dev. A detached `sleep` process with cwd=activeroot stands in for the
# live supervisor and its pid is written to the pid file.
#
# The FATAL at the end of case 2 is the harness, not the change: the throwaway
# devroot has no .orchestrator/supervisor_watchdog.py to record the restart
# intent against. Root syncing has already completed at that point.

## Case 1 - no resolvable live supervisor: behave exactly as before

$ PANTHEON_SUPERVISOR_PID=/tmp/syncsmoke/nonexistent.pid \
    bash scripts/sync-dev-root.sh /tmp/syncsmoke/devroot /tmp/syncsmoke/live-config.json

[sync-dev-root 2026-07-27T18:40:37Z] updated dev-root -> a20eac4
[sync-dev-root 2026-07-27T18:40:37Z] done (updated=1 config_updated=0)
