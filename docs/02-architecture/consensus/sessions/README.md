# Planning Session Records

This directory stores Pantheon's discussion-planning session records.

Every child session directory is a working record:

- session brief
- planning-session state
- readouts
- review rounds
- consensus packets
- execution materialization drafts

The active session is the one named by `.orchestrator/planning-state.json`.
Even the active session remains a planning record, not immutable blueprint truth.

Use `DOCUMENT_AUTHORITY_AND_RECORD_BOUNDARY.md` for the governing rule.
