## Summary
Build a conservative controller that closes the gap between `review_approved`
tasks and merged `dev` PRs. It should only merge clean, green task PRs; conflict
or CI failures must create an unblock task instead of stranding work.

## Scope
scope:

## Acceptance
- Auto-integrator scans active `review_approved` tasks and maps them to
  `task/<TASK-ID>` PRs into `dev`.
- Default mode is dry-run; `--execute` is required for git/GitHub/task-state
  mutations.
- Integration is serialized with a lock.
- Green clean PRs rebase onto `dev`, run smoke, and merge.
- Rebase conflicts, red CI, missing PRs, or unsafe PR states produce
  `INTEGRATION-UNBLOCK-*` tasks instead of hard merging.
- Unit tests cover candidate selection, check classification, dry-run merge
  planning, red-CI unblock, and rebase-conflict unblock.
